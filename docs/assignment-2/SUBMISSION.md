# Assignment 2 — Vague-prompt variant

This branch is the first variant in the prompt comparison. The source is `src/App.tsx`; it replaces the starter dashboard with a broad notification-settings experience.

For the structured version and full comparison, see [`fe02-spec`](https://github.com/NiknaxTheGreek/flyrank-frontend-capstone/tree/fe02-spec) and its [workflow analysis](https://github.com/NiknaxTheGreek/flyrank-frontend-capstone/blob/fe02-spec/WORKFLOW.md).

## Reproduction

```sh
npm ci
npm run dev
npm run build
```

No automated test script is defined for this variant.

`npm ci` and `npm run build` passed on 2026-11-21 with Node.js 24.22.3 and npm 11.19.1.
